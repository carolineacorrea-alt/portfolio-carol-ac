# Portfólio (site estático)
Sem build nem dependências. Abra `index.html` no navegador.
- Conteúdo: edite só `content.js` (um objeto por case; tags m/g/a = medido/meta/ausente).
- Publicar grátis: arraste a pasta em Netlify Drop, ou use GitHub Pages / Cloudflare Pages. O Google Drive guarda os arquivos, mas não hospeda o site.
- Não publique PDFs/decks originais (confidenciais); só esta pasta.
- Não testado em navegador; não publicado.
